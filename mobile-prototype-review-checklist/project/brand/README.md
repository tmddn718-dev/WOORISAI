# 우리사이 심볼 로고 — Connection Knot

두 개의 연결된 형태(매듭)와 중앙의 함께 만든 추억(원)을 표현한 심볼.

| 파일 | 용도 |
|---|---|
| `woorisai-symbol.svg` | 심볼 단독형 · 앱 아이콘 내부, 파비콘 |
| `woorisai-symbol-mono-green.svg` | 그린 단색형 · 밝은 배경, 인쇄물 (원은 투명 컷아웃) |

| 레이어 | 요소 | 색상 |
|---|---|---|
| `background` | 둥근 사각형 배경 (100×100, rx 26) | #566B5C |
| `connection-knot` | 매듭 형태 곡선 패스 | #FAF9F6 |
| `shared-memory` | 중앙 원 (r 9) | #566B5C |

viewBox 0 0 120 120 · 기본 출력 1024px.
