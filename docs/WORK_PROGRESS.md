## 2. 미완료 작업

### 제품 기능
- 실제 지도 화면(지도 SDK, 좌표 설계, 정확 좌표 최소화)
- 타임캡슐, 연도별 회고, 기록 기반 여행 경로
- 회상 푸시 알림, 알림 설정(빈도·조용한 시간)
- 로그인 방법 관리(다른 제공자 연결·해제, 마지막 수단 보호), 계정 복구 절차 (간편가입 문서 AUTH-FR-12, FR-13)

- 닉네임 변경 빈도 제한, 닉네임 신고 전용 경로
- 닉네임 분석 이벤트 등 KPI 측정(NICK-14, 통합 PRD §16)

### 운영·출시 준비

## 3. 발견된 버그와 해결해야 할 문제

심각도: **높음**(출시 전 필수) / 중간 / 낮음. 근거는 코드에서 직접 확인한 것에 `확인함`을 붙였다.

### 보안·안정성
| ID | 심각도 | 문제 | 근거 |
|---|---|---|---|
| B-01 | 높음 | **세션이 만료되지 않는다.** `sessions` 테이블에 생성·만료 시각이 없고 로그아웃·계정 삭제 때만 지워진다. 쿠키 `Max-Age`(30일)가 지나도 토큰 자체는 DB에서 계속 유효하다 | 확인함 (`server.js:17`, 삭제는 로그아웃·탈퇴뿐) |
| B-02 | 높음 | OAuth가 `state`만 검증한다. PKCE, `nonce`, ID 토큰(`iss/aud/exp/서명`) 검증이 없고 Google은 userinfo 응답만 신뢰한다. 간편가입 문서 §10은 이를 권장한다 | 확인함 |
| B-03 | 높음 | 리디렉션 URI가 `BASE_URL`이 없으면 요청의 `Host` 헤더로 만들어진다. 운영에서는 반드시 `BASE_URL`을 설정해야 한다 | 확인함 |
| B-04 | 높음 | `Secure` 쿠키 속성이 프록시가 `x-forwarded-proto: https`를 보낼 때만 붙는다. HTTPS 종단 환경에서 설정이 빠지면 세션 쿠키가 평문으로 갈 수 있다 | 확인함 (`server.js:79`) |
| B-05 | 중간 | 요청 제한(`tries`, `checks`)이 서버 메모리에만 있다. 재시작하면 초기화되고, 시간이 지난 키는 읽을 때만 걸러져 **조회되지 않는 키는 영구히 남는다**. 키가 IP 기준이라 프록시 뒤에서는 모든 사용자가 같은 IP로 보인다 | 확인함 (`server.js:75,149`) |
| B-06 | 중간 | 이름(아이디) 확인 API와 사람 연결 오류가 계정 존재 여부를 알려준다. 의도된 동작(공개 식별자)이고 호출 제한이 있으나, 제한이 B-05의 약점을 그대로 가진다 | 코드 확인 |
| B-07 | 중간 | `/api/invites/:code/peek`는 링크를 아는 누구에게나 초대한 사람의 이름을 보여준다. 문서가 허용한 최소 정보지만 링크 유출 시 이름이 노출된다 | 설계 의도 |
| B-08 | 낮음 | `node:sqlite`가 Node의 실험 기능이라 경고가 나올 수 있고 Node 24 이상이 필요하다 | 환경 |

### 정책·제품 격차
| ID | 심각도 | 문제 |
|---|---|---|
| B-09 | 높음 | 이용약관·개인정보처리방침이 임시 문구다. 동의 기록은 `2026-11-10-draft` 버전으로 저장된다. 정본이 확정되면 버전 갱신과 기존 사용자 재동의 흐름이 필요하다 |

| B-16 | 낮음 | 카카오·네이버 버튼의 글자색과 배경이 제공자 공식 규정과 맞는지 확인하지 않았다. 네이버는 접근성(대비) 때문에 어두운 글자를 썼다 |

## 4. 다음 작업 우선순위

### P0 — 실제 사용자에게 열기 전에
1. **세션 만료·정리** (B-01): `sessions`에 만료 시각을 두고 요청마다 확인, 오래된 행 정리, 로그인 시 기존 세션 정책 결정
2. **운영 환경 설정 고정** (B-03, B-04): `BASE_URL` 필수화, HTTPS에서 `Secure` 보장, 요청 제한 키·정리 방식 점검 (B-05)

4. **약관 정본 확정** (B-09): 법률 검토를 거친 문서로 교체하고 동의 버전 관리와 재동의 흐름 마련
5. **신고·개인정보 요청 운영 화면** (B-10): 최소한의 목록·상태 변경·감사 로그

### P1 — 출시 직후 안정화
